如何加载（Chrome / Edge）：
1) 打开 chrome://extensions 或 edge://extensions
2) 开启「开发者模式」
3) 点击「加载已解压的扩展程序」
4) 选择本目录（tuwen-extension）

说明：
- popup 默认宽度 600px（浏览器会在允许范围内尽量遵循）
- 左右分栏支持拖拽调整比例，松开鼠标后会自动保存（下次打开仍生效）
- 展示区支持设置列数（自动/2~6 列）
- 滚动条已调整为更细、更短的样式（仅影响扩展内部）
- 新增「JSON识别」模式：判断是否合格JSON；不合格时定位行列并高亮错误片段；合格时支持树形层级折叠查看，支持格式化与复制格式化
- 新增「新标签页打开」按钮：弹窗空间不够时可在独立标签页查看（更适合看图片细节）
- 图片预览支持：滚轮缩放 + 拖拽平移 + 复位（双击图片也可复位）
- 图片模式新增：抓取当前页图片、过滤小图（<32px）、ZIP 打包下载（选中/全部）
- 网页文本模式：抓取整页正文，或在原网页上多选内容区域
- 支持直接输入网页链接抓取；普通 HTML 后台直读，动态网页自动回退到渲染后提取
- 飞书/Lark 文档使用页面增强抓取：自动定位主滚动容器、逐屏采集虚拟加载内容、去重合并并恢复原滚动位置
- “网页抓取”为顶部独立入口，不再与图片、文本、JSON 处理模式混合
- 抓取后可二次勾选、删除和编辑章节，并导出 Word（.docx）、Markdown（.md）或纯文本（.txt）
- 结果页使用独立吸顶操作栏，可随时新建抓取、按原来来源重新抓取、复制或导出
- 侧边栏使用单列紧凑界面，独立标签页使用目录/文档/导出三栏工作台，两端共享最近结果
- JSON 模式新增：搜索 key/value 返回路径列表；超大内容历史使用 IndexedDB 存储避免 localStorage 上限

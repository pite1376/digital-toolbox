# Chrome Web Store 上架文案

## 单一用途

在浏览器本地采集、清洗、整理并导出用户主动指定的网页和文本内容。

## 简短说明

本地抓取网页正文和图片，清洗文本与 JSON，并导出为 Word、Markdown 或纯文本。

## 详细说明

内容工坊 ContentForge 是一款本地内容采集与整理工具。用户可以主动抓取当前网页正文、选择网页中的特定内容区域、提取网页图片，或粘贴文本、JSON 和图片链接进行清洗与整理。

主要功能：

- 抓取当前网页正文或用户选择的内容区域；
- 读取用户输入的网址并整理网页结构；
- 提取、预览、复制和批量下载网页图片；
- 清洗文本和格式化 JSON；
- 对抓取结果进行选择、删除和编辑；
- 导出 Word、Markdown、TXT 或 ZIP 文件。

所有处理均由用户主动触发。扩展不设开发者数据服务器，不会把处理内容上传给开发者；设置、处理历史和最近结果保存在用户浏览器本地。

## 权限用途说明

### storage

保存界面设置、最多 50 条本地处理历史和最近一次网页抓取结果。

### scripting

仅在用户点击抓取或选择内容时，向目标网页注入扩展自带的内容提取脚本。

### sidePanel

在 Chrome 侧边栏中显示 ContentForge 的主要操作界面。

### host permissions (`http://*/*`、`https://*/*`)

核心功能需要处理用户当前打开的网页、用户明确输入的网址以及这些网页中的图片资源。网站权限仅在用户主动发起抓取、预览、复制或下载时使用，不用于后台浏览监控。

## 数据披露建议

在 Privacy practices 中如实申报：

- Website content：是，仅在本地处理；
- Web history / browsing activity：会读取用户主动处理页面的 URL，不持续收集浏览历史；
- User-provided content：是，包括用户粘贴的文本、JSON 和链接；
- 数据出售：否；
- 用于广告：否；
- 传输至开发者服务器：否；
- 第三方网络请求：仅在用户主动操作时直接请求用户指定的目标网页或图片地址，不向其他第三方传输处理内容；
- Remote code：否；
- Limited Use certification：确认遵守。

## 审核测试说明

1. 安装扩展后点击工具栏图标，侧边栏自动打开。
2. 打开任意公开的 HTTP/HTTPS 文章页面。
3. 点击“网页抓取”，选择“抓取当前网页”验证正文提取。
4. 选择“在当前网页选择内容”，在原网页点击若干区域并完成选择。
5. 切换到图片模式，点击抓取当前页图片并测试预览及 ZIP 导出。
6. 在文本和 JSON 模式粘贴示例内容，验证清洗、格式化、复制和导出。
7. 打开历史记录并点击“清空”，验证本地历史删除。

扩展不需要登录账号，也没有隐藏或付费功能。

## 待准备素材

- 1280×800 截图至少 1 张，建议准备 3–5 张；
- 440×280 小型宣传图；
- 1400×560 Marquee 宣传图（可选）；
- 隐私政策公开 HTTPS URL；

# 内容工坊 ContentForge

> Capture, clean, organize, and export web content.

ContentForge 同时提供浏览器扩展和静态网页版。扩展版可抓取当前网页、多选页面区域和读取虚拟滚动文档；网页版可完成文本、JSON、图片链接和文档导出处理。

## Load the extension

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 `projects/contentforge/extension` 目录。

## Web and extension differences

GitHub Pages 是静态托管。网页版不能读取用户当前标签页、注入其他网页或复用登录态；这些功能只在扩展版中提供。
